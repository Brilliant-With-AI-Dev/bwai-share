# Wow bar (Adrian — copy/prose/HTML)

**Scope (6A):** Applies to copy, prose, and deploy-linked HTML — not engineering
code artifacts. Code stays on engineering skills.

## The bar

Whoever uses this should **immediately get it**. Then they should feel genuinely wowed.
They should resonate right away and see how useful it is. Anything obvious, safe, or
merely competent misses the bar. The real win: they spot things they wanted but could
not name themselves — and walk away struck by how clear and insightful it is.

## Checkable signals

Portable defaults; repo `copy-deliverable.repo.yaml` may add more.

- **Purpose-first lede** — states job of artifact + what it is *not*.
- **Coined terms defined before use** — or embedded in the question/bullet itself.
- **Self-contained bullets** — each line works without the section title or offsite context.
- **Primary reader named** when it matters (Matt vs Tev vs client vs facilitator).
