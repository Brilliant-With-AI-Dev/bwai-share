Behavior rules (for when this becomes code):
  • Rail: resting state is section numbers only; hover or keyboard focus expands it over the content to the full numbered titles; it never pushes the letter around. Mobile keeps the Sections sheet.
  • Chat default: sidecar open on ≥1280px viewports; below that it starts minimized (the header button). Mobile keeps today's behavior — chat reachable via "Ask", no sidecar.
  • Persistence: chat open/closed remembered per device. The rail has no state to remember.
  • Naming: the chat surface is "Chat With Mirror" everywhere (panel title, header button, mobile entry).
  • Export: one menu, three targets (Mirror / Next Moves / Both in one) × two forms (Copy, PDF). "Both in one" is a single document: letter first, plan second, one continuous PDF.
  • Next Moves: layout comes from PR #1520 (rebased), rendered inside this shell; the moves become the rail's anchors on that tab.
  • Print/PDF: sidecar, header, and rail are excluded, like the rest of the chrome.
  • No chat-internals change: same chat engine and grounding as today — placement and naming only.
