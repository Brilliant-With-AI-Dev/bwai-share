Saved Mirror — chat sidecar & shrinkable nav

2026-08-06 — wireframes only (no code yet). Three changes to the merged reading surface: ① chat moves out of the page bottom into a right-hand sidecar, ② the sidecar is open by default on laptop and minimizes to a pill, ③ the Contents rail shrinks to a numbers-only strip. Gray boxes = existing content, unchanged. Green = the surface accent where a state needs it.

1 · Laptop default — chat open in a sidecar

The chat panel sits to the right of the letter, full height under the header. The letter column keeps its reading measure; the Contents rail stays as-is on the left. "Ask about this" disappears from the header — the sidecar is the ask surface, so the header slims down to brand · tabs · section indicator · Export · ⋯ · account.

Behavior rules (for when this becomes code):
  • Default: sidecar open on ≥1280px viewports; below that it starts minimized (the pill). Mobile keeps today's behavior — chat reachable via "Ask", no sidecar.
  • Persistence: sidecar open/closed and nav shrunk/expanded are remembered per device.
  • Header: "Ask about this" leaves the header on laptop (the sidecar replaces it); the mobile "Ask" button stays.
  • Print/PDF: sidecar and pill are excluded, like the rest of the chrome.
  • No chat-internals change: same chat engine and grounding as today — this is placement only.
