Behavior rules (for when this becomes code):
  • Default: sidecar open on ≥1280px viewports; below that it starts minimized (the pill). Mobile keeps today's behavior — chat reachable via "Ask", no sidecar.
  • Persistence: sidecar open/closed and nav shrunk/expanded are remembered per device.
  • Naming: the chat surface is "Chat With Mirror" everywhere (panel title, pill, mobile entry).
  • Export: one menu, three targets (Mirror / Next Moves / Both in one) × two forms (Copy, PDF). "Both in one" is a single document: letter first, plan second, one continuous PDF.
  • Next Moves: layout comes from PR #1520 (rebased), rendered inside this shell; its move list doubles as the shrunken rail's anchors on that tab.
  • Print/PDF: sidecar and pill are excluded, like the rest of the chrome.
  • No chat-internals change: same chat engine and grounding as today — placement and naming only.
