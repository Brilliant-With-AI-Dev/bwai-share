Saved Mirror — nav Alt B

Replaces the numbered rail with a reading-progress bar plus a contents list opened from the header. Wireframes, not visual design — same grey-box vocabulary as mirror-chat-sidecar rev 5.

Why the rail is being replaced. Nine bare digits carry no meaning, and every section title sits behind a hover the reader has no reason to attempt — the interface asks them to recall what "4" is instead of letting them recognise it. There is also no signal for how far through the letter they are.
  • Progress becomes explicit. A 3px bar on the header's bottom edge fills as they read.
  • Titles become legible. The header already names the current section; making it the control means the affordance explains itself.
  • One navigation, not two. Desktop and mobile use the same control, so there is no separate mobile pattern to maintain.
  • The gutter comes back. With the rail gone the letter centres properly even with the chat sidecar open.

1 — Desktop at rest (≥1280px)

No left rail. The header's centre is now the section control: position, title, caret. The progress bar sits on the header's bottom edge. The letter is centred in the full width the rail used to eat.

4 — The pieces, spelled out

Progress bar

3px, on the header's bottom edge, full-bleed. Fills against scroll position through the active tab's document. It is the only new persistent element, and it replaces nine.
read remaining

Section control

Position (3 / 9) + current title + caret. Already exists as a passive scrollspy indicator in the shipped header — this makes it interactive. Truncates to the position pair when space is tight.

Contents states

Read grey + tick, current green on tint, unread navy. Read-state is derived from furthest scroll reached, not from clicks, so it survives a reload.

5 — What this changes against rev 5

  • Number rail and its hover-expanded overlay: removed.
  • Header scrollspy indicator: becomes the nav control.
  • Progress bar: new.
  • Contents overlay (desktop) / sheet (mobile): new, replaces the rail's hover state.
  • Letter measure: unchanged; it just centres in the reclaimed width.
  • Chat sidecar, Export menu, tabs: unchanged.
  • Chat opens with fixed prompt chips instead of a written greeting — decided separately, shown here because it is the same surface.
Wireframes only — grey boxes stand in for real type and colour. Agent-made and unreviewed; the layout decisions are the point, not the pixels.
