# Mission: Master SSSF

## Why
Understand SSSF deeply enough to change its workflows, agent roles, and safeguards with confidence. Then use it on real projects without hidden cost, unreliable results, or avoidable damage.

## Success looks like
- Explain what Python, agents, and the engineer each own
- Read an ADW and predict its phases, handoffs, retries, and finish condition
- Customize the roster, prompts, quality commands, write limits, and gates
- Run a safe pilot, inspect its trace, and judge whether the result earned acceptance
- Recognize when SSSF is useful and when a direct agent prompt is simpler

## Constraints
- Teach internals and customization before practical operation
- Use short, plain-English, source-backed lessons
- Build durable recall through small interactive exercises
- Never launch paid agent workflows without explicit approval

## Out of scope
- Building a replacement orchestration framework
- Production use before a disposable pilot proves the setup
- Claude Code as a worker runtime until SSSF implements it
