Who runs what?

One rule explains the factory: code owns the workflow; agents own only the judgment inside bounded steps.

Goal · classify workNo setup needed
Your win By the end, you can look at a task and decide whether an engineer, Python, or an agent should own it.

The problem SSSF addresses

A normal “do everything” prompt asks one model to plan, act, check itself, retry, and decide when it is done. Those boundaries live only in its conversation. When something fails, you cannot easily name which step failed or apply the same recovery every time.

SSSF moves those boundaries into a Python workflow called an ADW: AI Developer Workflow. The ADW names each phase, runs it, records it, and decides whether the full run is accepted.

Engineer

Sets intent

Provides the request and defines what outcome matters.

Python

Owns the loop

Sequences phases, runs known commands, limits retries, and accepts or rejects.

Agent

Uses judgment

Reads, plans, builds, or reviews inside one named phase.

See the split in one real workflow

The starter plan_build_test workflow makes the ownership visible:

Why does code run tests? Because the command is already known. No model judgment is needed to execute bun test. If tests fail, code sends the exact failure back to the builder agent. Python limits that repair loop to three attempts. Only a green result reaches commit.

The classification rule If the invocation is known, use code. If the step requires reading and deciding, use an agent. Keep human intent in the engineer lane.

Retrieval practice

Classify each step before clicking. Difficulty here helps the rule stick.

1. Run the repository’s fixed test command.

2. Decide whether the implementation matches the request.

3. Commit work after the test phase passes.

Check your understanding

  • I can explain why Python—not the model—owns retries and acceptance.
  • I can classify a known command as code-owned work.
  • I can classify reading and deciding as agent-owned work.

If any line feels uncertain, ask your agent a follow-up before continuing.
