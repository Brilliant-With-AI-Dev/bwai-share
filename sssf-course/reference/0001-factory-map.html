Classification rule

Known invocation → code phaseReading and deciding → agent phase. Human purpose → engineer lane.

Core terms

  • ADW: Python script defining one repeatable workflow.
  • Phase: One named unit owned by engineer, code, or agent.
  • Roster: Configured agents, models, tools, prompts, and write limits.
  • Envelope: Typed JSON report passed between phases.
  • Gate: Code check that verifies an agent’s claim.
  • Trace: SQLite record of phases, events, outputs, cost, and status.
  • Acceptance: Final explicit decision made by run.finish().
