The main comparison

/ask-matt main flow

SSSF match: the whole ADW—the saved sequence of roles and checks.

/grill-with-docs

SSSF use: sharpen important requests before starting the automated run.

/to-prd + /to-issues

SSSF match: planner turns the request into build-ready work.

/implement

SSSF match: builder reads the plan and changes the product.

/tdd

SSSF match: builder changes code; fixed test commands check it.

/review-branch

SSSF match: reviewer checks the result against the request.

/handoff

SSSF match: shared files plus a short summary move forward automatically.

What changes

Matt skills

Guided flow

You or the agent chooses and starts the next skill.

SSSF

Saved flow

Python starts the next role and applies fixed retry rules.

Both

Separate jobs

Each role gets focused context and leaves work for the next.

Plain-English glossary

  • ADW: saved skill sequence.
  • Roster: available role list.
  • Envelope: short handoff summary.
  • Gate: automatic yes-or-no check.
  • Trace: history of what ran.
When SSSF earns its keepUse the normal Matt skill flow for one-off work. Consider SSSF when the same settled sequence must run repeatedly.
